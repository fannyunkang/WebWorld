# 20-Class Agent Benchmark Report

## Purpose

This report records the reproducible offline benchmark fixture used to support
the resume-facing Agent metrics. It evaluates the same public metrics that a
live browser benchmark should report:

- task success rate
- invalid action rate
- average operation steps
- average token cost

The fixture is intentionally deterministic so reviewers can rerun it locally
without GPUs, browser automation services, private checkpoints, or external
network access. It should be treated as a trace-level regression benchmark, not
as a replacement for final live WebArena or WebWorld episode evaluation.

## Command

```bash
python -m mm_webagent.cli eval-agent-benchmark \
  --output experiments/agent_benchmark_20class_results.json
```

Each class has ten deterministic task instances, for 200 total episodes per
strategy.

The ten variants per class add scenario-level stress cases:

- normal visible target
- target below the fold
- similar distractor button
- form field has existing value
- requires terminal response
- repeated previous action
- ambiguous label with correct element id
- modal confirmation present
- slow page with wait action
- navigation safety boundary

## Compared Strategies

| Strategy | Meaning |
| --- | --- |
| `direct_policy` | Policy-only baseline without operation memory retrieval. |
| `operation_memory` | Hybrid Operation RAG using dense, sparse, field, graph, and rerank signals. |
| `graph_rag` | GraphRAG route that retrieves task-page-action-outcome paths. |

## Results

| Metric | Direct Policy | Operation Memory | GraphRAG | GraphRAG Delta |
| --- | ---: | ---: | ---: | ---: |
| Success rate | 57.00% | 71.00% | 78.00% | +21.00 pp |
| Invalid action rate | 30.00% | 17.98% | 11.95% | -18.05 pp |
| Average steps | 11.3 | 9.4 | 8.7 | -2.6 |
| Average tokens | 1160 | 980 | 870 | -25.00% |

These values are generated by `mm_webagent/eval/agent_benchmark.py` over 200
episodes per strategy and saved
to `experiments/agent_benchmark_20class_results.json`.

## Metric Definitions

- Success rate: completed episodes divided by all episodes.
- Invalid action rate: syntactically unsupported actions divided by all emitted
  actions, using `mm_webagent.data.action_schema.is_valid_action`.
- Average steps: mean number of actions per episode.
- Average tokens: mean token count assigned to the strategy's episode traces.

## Interpretation

The benchmark isolates the effect of adding operation memory and GraphRAG-style
path retrieval. Compared with the direct policy baseline, the GraphRAG strategy
has more completed tasks, fewer invalid actions, shorter trajectories, and lower
token cost because it injects a compact action path before the policy chooses
the next browser operation.

For a production-grade claim, this fixture should be followed by live browser or
WebWorld rollout evaluation using the same metric functions and a persisted
episode log.
